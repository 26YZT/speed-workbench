## 交互与使用体验

- 产品工厂、模型对比台、助手、定时任务采用同级导航；选中状态和悬停反馈分别表达。
- 模型对比输入、材料、模型选择和已有回答可恢复；中断后的恢复不会自动重新调用模型。
- 新产品草稿与已有产品分开保存；补充字段也参与本地保存。
- 未保存的访谈、蓝图和任务编辑可恢复；服务端版本冲突时保留本地内容，提供预览、导出与显式丢弃。
- 展示接口返回的全部历史产品，每个产品可单独进入；按当前阶段展示下一步操作。
- 预算保留原始输入，拒绝非有限或非正数，阻止无效提交；预算可以留空。
- 改进工具栏、底栏及团队入口的键盘交互，并统一内置示例中的产品品牌。

# L2 验收基线（2026-10-06）

本记录对应单 Leader、人工 Review、显式顺序推进的本地产品开发 MVP。后续改动另列验证记录，不改写本次历史证据。

## 已实现

- 需求、蓝图和四阶段任务为可编辑的规则草稿；开发由配置好的真实 Agent 执行。任务携带完整确认蓝图，不再限定标题工具。
- 首任务派发、人工批准/打回、明确继续与中断恢复已接线；pending/uncertain 不自动重发，运行中拒绝重复派发。
- 普通任务目录隔离，最终任务可组装项目根目录。未填目录时创建独立目录，新建产品不继承上一产品路径与预算。
- 用量持久化、预算准入与查询异常暂停、未知金额保护、交付检查展示和成本 JSON 下载。
- 活跃流程只读轮询，页面隐藏时跳过；许可证与上游归属随本地包保留。
